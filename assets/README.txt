========================================================================
VEDANT PANDEY - ASSETS DIRECTORY
========================================================================

Place your personal files here:

1. PROFILE PHOTO:
   - Save your headshot or profile photo in this folder.
   - Name it `profile.jpg` (or update `profileImage` in `js/script.js` with your filename).
   - Recommended resolution: 400x400 to 800x800 px (Square aspect ratio).

2. RESUME FILE:
   - Place your PDF resume in this folder.
   - Name it `resume.pdf` (or update `resume` in `js/script.js` with your filename).

3. PROJECT SCREENSHOTS:
   - Place project preview images inside `assets/projects/` (e.g. `rf-detection.jpg`, `waste-management.jpg`, `portfolio-preview.jpg`).
